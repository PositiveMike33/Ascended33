# Preuves THIRTY3

Ce dossier contient les preuves exceptionnelles documentées.

## Format d'une preuve

Crée une note avec le format : `YYYY-MM-DD — [Description courte].md`

Exemple : `2026-02-20 — Premier engagement HexStrike complété avec rapport livré.md`

## Quand créer une preuve dédiée

- Quand la preuve du jour est notée "Exceptionnelle" dans le Protocole Soir
- Quand un milestone important est atteint (première certification, premier client, etc.)
- Quand une red line a été tenue dans une situation difficile
- Quand un engagement HexStrike est livré avec succès

Les preuves du jour ordinaires sont enregistrées dans la note quotidienne via le champ `preuve_du_jour`.

## Structure suggérée pour une preuve dédiée

```markdown
# [Titre de la preuve]

**Date :** YYYY-MM-DD
**Domaine :** THIRTY3 / HexStrike / Apprentissage
**Niveau :** Exceptionnel

## Ce qui s'est passé

[Description factuelle]

## Pourquoi c'est une preuve THIRTY3

[Quel standard a été démontré, quelle red line a été tenue]

## Ce que ça confirme

[Sur qui je suis, sur ma progression]
```
