# THIRTY3 — Système de Vie

Bienvenue dans le système THIRTY3 de Michael.

## Structure

| Dossier | Rôle |
|---------|------|
| `Daily/` | Notes quotidiennes auto-générées chaque matin |
| `Templates/` | Templates Templater (ne pas modifier directement) |
| `Protocoles/` | Documents de protocole permanents |
| `Preuves/` | Archive des preuves exceptionnelles |

## Comment démarrer chaque journée

1. Ouvre Obsidian
2. Utilise le raccourci Daily Notes (`Ctrl/Cmd + P` → "Open today's daily note")
3. La note du jour est auto-créée avec le template THIRTY3 complet
4. Complète la section **Matin** avant de commencer à travailler
5. Consulte [[MATIN — Activation THIRTY3]] pour le protocole complet

## Comment clore chaque journée

1. Retourne à la note du jour dans `Daily/`
2. Complète la section **Soir** avec tes scores honnêtes
3. Remplis le YAML frontmatter (`score_alignement`, `preuve_du_jour`, etc.)
4. Consulte [[SOIR — Bilan THIRTY3]] pour le protocole complet

## Suivi Dataview
