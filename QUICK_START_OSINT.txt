================================================================================
  SÉCURITÉ PAR COUCHE
================================================================================

Couche 1: ANONYMITÉ RÉSEAU
  ✅ Tor obligatoire (SOCKS5:9050)
  ✅ Zéro logs exposant l'opérateur
  ✅ Métadonnées anonymes en opération
  ✅ Session ID anonyme

Couche 2: AUDIT TRAIL CHIFFRÉ
  ✅ AES-256-GCM encryption
  ✅ Clé 32-bytes personnelle
  ✅ Accès personnel UNIQUEMENT
  ✅ Vérification d'intégrité

Couche 3: SIGNATURES LÉGALES
  ✅ RSA-4096 PSS-SHA256
  ✅ Clé privée: osint_private.pem (À PROTÉGER!)
  ✅ Clé publique: osint_public.pem (À partager)
  ✅ Vérifiable par autorités

Couche 4: CHAIN OF CUSTODY
  ✅ Chaîne de preuves imbriquée
  ✅ Impossible d'altérer
  ✅ Timestamps UTC vérifiables
  ✅ Hashes SHA256 pour chaque IOC

================================================================================
  TROUBLESHOOTING
================================================================================

❌ Docker n'est pas installé
   → Installez Docker Desktop: https://docker.com

❌ Tor n'est pas actif
   → Vérifiez port 9050, relancez conteneur tor
   → docker logs ascended33-th3-tor-1

❌ Service Hexstrike inaccessible
   → Vérifiez conteneur: docker logs ascended33-th3-hexstrike-1
   → Attendez 30 secondes pour startup complet

❌ Erreur Python packages
   → pip install cryptography docker requests

⚠️  Services lents au démarrage
   → Normal, attendez 40 secondes maximum
   → Vérifiez RAM disponible (4GB minimum)
