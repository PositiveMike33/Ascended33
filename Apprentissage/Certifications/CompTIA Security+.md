## Concepts Clés à Maîtriser

### Cryptographie
- Symétrique (AES) vs Asymétrique (RSA, ECC)
- Hashing (SHA-256, MD5) vs Chiffrement
- PKI — Certificate Authority, certificats X.509
- TLS/SSL — handshake, versions
- Signatures numériques

### Authentification et Accès
- MFA — facteurs (quelque chose que tu sais/as/es)
- LDAP, Kerberos, RADIUS, TACACS+
- RBAC, ABAC, MAC, DAC
- SSO, OAuth, SAML, OpenID

### Sécurité Réseau
- Firewalls (stateful, stateless, next-gen)
- IDS vs IPS
- VPN (SSL, IPSec)
- DMZ, segmentation réseau
- DNS Security (DNSSEC)

### Réponse aux Incidents
- Phases : Préparation → Détection → Confinement → Éradication → Récupération → Leçons apprises
- SIEM — centralisation des logs
- Forensique digitale — chaîne de possession
