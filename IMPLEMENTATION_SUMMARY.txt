ANONYMITY IMPLEMENTATION

Report ID Generation:
  ├─ Cryptographic hash of source data + entropy
  ├─ Session salt: Random bytes (32)
  ├─ Format: ANON_[16-char hex]
  ├─ Cannot be reversed or traced
  └─ Unique per report generation

Indicator Hashing:
  ├─ SHA256 initial hash
  ├─ Blake2 secondary hash
  ├─ Session salt applied
  ├─ Structure preserved:
  │  ├─ Domain → [DOMAIN]_[hash]
  │  ├─ IP → [IP]_[hash]
  │  └─ Email → [EMAIL]_[hash]
  └─ Cannot be reverse-engineered

Timestamp Variance:
  ├─ Original time recorded
  ├─ Random variance: ±minutes
  ├─ Applied: ±30 minute range
  ├─ ISO format: [original ± variance]
  └─ Prevents time-based correlation

User Information Removal:
  ├─ Logs filtered with AnonymousFilter
  ├─ All paths: [HOME] tags
  ├─ Username: [USER] tags
  ├─ No session IDs saved
  ├─ No user traces in outputs
  └─ Reports show: CLAUDE_ANALYSIS

Plausible Deniability:
  ├─ Field order randomized
  ├─ Entropy added per report
  ├─ Timestamp variance ±
  ├─ Output formatting varied
  └─ Cannot fingerprint generator

Cross-Reference Prevention:
  ├─ Session entropy: Unique per run
  ├─ Report ID: Cannot be sequential
  ├─ Timestamp: Variance applied
  ├─ Indicators: Hashed differently per report
  └─ Result: Impossible to link reports
