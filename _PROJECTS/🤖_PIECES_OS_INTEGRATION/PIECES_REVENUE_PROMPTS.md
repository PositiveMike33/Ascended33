## PROMPT 1: Service Ideation

```
Title: Service Ideation Prompt
Description:
  Generate new service ideas quickly using Claude.
  Use this when: You want to brainstorm revenue opportunities
  How to use: Paste prompt + provide context + get 5-10 ideas
  Collection: Revenue-Prompts
Tags: #prompt #revenue #ideation
```

**Prompt to paste:**
```
You are a business strategist helping generate viable service ideas.

CONTEXT:
- Your skills: [describe your skills, what you're good at]
- Target market: [who you want to serve]
- Budget/time available: [how much you can invest]
- Desired revenue per project: [what income you want]

TASK:
Generate 5-10 specific, viable service ideas that:
1. Leverage your existing skills (no expensive training needed)
2. Can be sold within 4-6 weeks
3. Target your market directly
4. Generate $2-10K per project minimum

For each idea, provide:
- Service name
- Problem it solves
- Who buys it
- Price range
- Effort to deliver (hours/days)
- Revenue potential

Rank them by: Ease of implementation + Revenue potential

FORMAT:
Service Name: [name]
Problem solved: [concise]
Target buyer: [person/company]
Price: $X-Y per project
Effort: X hours/days
Potential: $X/month if 1-2 projects/month
Quick wins: [why this is doable fast]
```

## PROMPT 2: Pricing Strategy

```
Title: Pricing Strategy Prompt
Description:
  Calculate optimal pricing for any service using market data.
  Use this when: You need to price a new service
  How to use: Paste prompt + provide service details + get 3 pricing models
  Collection: Revenue-Prompts
Tags: #prompt #revenue #pricing
```

**Prompt to paste:**
```
You are a pricing strategist. Help me price a new service.

SERVICE DETAILS:
- Service name: [name]
- Problem it solves: [what pain point]
- Target market: [who buys]
- Delivery effort: [X hours / X days]
- Competitor pricing: [what others charge, if known]
- Your positioning: [premium / value / discount]

TASK:
Provide 3 pricing models:

MODEL 1: Time-based (hourly/daily rate)
- Calculation: Your target hourly rate × estimated hours
- Pros: Predictable, flexible
- Cons: Uncertain total cost for client
- Best for: [when to use this model]

MODEL 2: Fixed-price (one-time project fee)
- Calculation: (Estimated hours × hourly rate) + margin + taxes
- Pros: Clear pricing, good for margins
- Cons: Risk if project takes longer
- Best for: [when to use this model]

MODEL 3: Value-based (percentage of value created)
- Calculation: [Your estimate of value created] × [% commission]
- Pros: Aligned with client value, high margins
- Cons: Requires trust, harder to explain
- Best for: [when to use this model]

RECOMMENDATION:
Which model is best for your service? Why?

MARKET ANALYSIS:
- Competitor pricing: $X-Y
- Your positioning: Better/Same/Cheaper
- Recommended price: $Z
- Rationale: [why this price]

NEXT STEPS:
1. Test pricing with [number] prospect conversations
2. Adjust based on feedback
3. Lock in pricing once you close first client
```

## PROMPT 4: Discovery Call Script

```
Title: Discovery Call Script Prompt
Description:
  Generate structured discovery call script for sales calls.
  Use this when: You're about to call a prospect
  How to use: Paste prompt + customize + use during call
  Collection: Revenue-Prompts
Tags: #prompt #revenue #sales #discovery
```

**Prompt to paste:**
```
You are a sales coach. Generate a discovery call script.

CONTEXT:
- Service name: [name]
- Problem it solves: [pain point]
- Prospect's situation: [what you know about them]
- Call duration: 15-20 minutes
- Goal: Understand their needs + book next meeting

TASK:
Create discovery call script with 5 sections:

SECTION 1: Opening (2 min)
- Greeting
- Rapport building
- Purpose of call
- Time check

Script:
---
[Write opening script here]
---

SECTION 2: Needs Discovery (8 min)
5 key questions:
1. [Ask about their current situation]
2. [Ask about their pain points]
3. [Ask about their attempted solutions]
4. [Ask about their ideal outcome]
5. [Ask about timeline/budget]

Script with follow-ups:
---
[Write discovery questions + follow-up probes]
---

SECTION 3: Solution Fit (4 min)
- How your service helps them
- Why you're uniquely qualified
- Quick case example (if available)

Script:
---
[Write solution positioning script]
---

SECTION 4: Next Steps (2 min)
- If interested: Book next meeting / send proposal / timeline
- If not interested: Appreciate their time, leave door open
- Always ask: "What's the best next step?"

Script:
---
[Write closing script with objection handling]
---

SECTION 5: Handling Objections (as needed)

Common objections:
1. "We already have [solution]" → [Your response]
2. "Too expensive" → [Your response]
3. "We'll think about it" → [Your response]
4. "Not the right time" → [Your response]

---

TIPS:
- Listen more than you talk (70/30 rule)
- Take notes
- Confirm their pain points at end
- Don't pitch too hard (discovery call, not sales call)
```

## PROMPT 5: Audit Report Generator

```
Title: Audit Report Generator Prompt
Description:
  Generate security audit findings report from vulnerability data.
  Use this when: You've completed an assessment, need to write report
  How to use: Paste prompt + provide vulnerabilities + get report structure
  Collection: Revenue-Prompts
Tags: #prompt #automation #audit #service
```

**Prompt to paste:**
```
You are a security report writer. Generate audit findings report.

AUDIT CONTEXT:
- Client: [company name]
- Assessment date: [date range]
- Assessment scope: [what was tested]
- System types: [networks, applications, infrastructure]
- Total vulnerabilities found: [number]

VULNERABILITIES FOUND:
[Provide list of vulnerabilities in this format]
1. [Vulnerability name]
   - CVSS score: X.X (severity)
   - Description: [what is it]
   - Impact: [business impact]
   - Remediation: [how to fix it]

TASK:
Generate professional audit report with sections:

SECTION 1: Executive Summary (1-2 pages)
- Key findings summary
- Risk level: Critical / High / Medium
- Immediate actions required
- Total remediation effort
- Expected timeline to remediate

SECTION 2: Findings Detail (by severity)
For each vulnerability:
- Vulnerability name + CVSS score
- Description (non-technical)
- Technical details
- Business impact
- Remediation steps
- Timeline to fix
- Cost estimate (if applicable)

SECTION 3: Remediation Roadmap (30/60/90 days)
- Week 1-2: Critical findings (immediate)
- Week 3-4: High findings
- Week 5-8: Medium findings
- Week 9+: Low findings + improvements

SECTION 4: Best Practices
- What they're doing well
- Top 3 improvements (beyond vulnerabilities)
- Long-term security strategy

SECTION 5: Next Steps
- Follow-up assessment date
- Ongoing monitoring recommendations
- Training recommendations
- Budget for remediation: $X-Y

FORMAT:
[Professional PDF-ready format]
[Include charts/statistics]
[Executive-friendly language]
[Technical appendix for IT team]

---

TONE:
- Professional but accessible
- Highlight urgency of critical items
- Provide clear action items
- Show value of remediation
- Position you as trusted advisor
```

## PROMPT 6: Follow-up Email Template

```
Title: Follow-up Email Template Prompt
Description:
  Generate personalized follow-up emails after discovery call.
  Use this when: You need to send proposal or check-in email
  How to use: Paste prompt + customize + send
  Collection: Revenue-Prompts
Tags: #prompt #revenue #email #templates
```

**Prompt to paste:**
```
You are a sales copywriter. Generate follow-up email.

CONTEXT:
- Recipient: [name + company]
- Previous interaction: [what you discussed in call]
- Purpose of email: Thank you + proposal / next meeting request
- Your service: [name + brief description]
- Call outcome: [interested / somewhat interested / lukewarm]

TASK:
Generate follow-up email with 4 sections:

SUBJECT LINE:
[Compelling but not salesy subject]
Examples:
- "Quick follow-up from our chat about [their pain]"
- "[Their name], here's that audit roadmap we discussed"
- "Action plan for [their company's specific problem]"

SECTION 1: Opening (Reference previous conversation)
- Personalized reference to call
- Positive note about conversation
- What impressed you about them

Script:
---
Hi [Name],

Thanks again for taking the time to chat about [specific topic they care about]. I really appreciated your insights on [specific thing they mentioned].
---

SECTION 2: Value Reminder (Recap what you discussed)
- Their main pain point
- Your solution for it
- Expected outcome/benefit

Script:
---
Based on our conversation, here's what I heard:
1. [Pain point 1]
2. [Pain point 2]
3. [Their desired outcome]

This is exactly what our [service] is designed to address...
---

SECTION 3: Next Steps (Clear CTA)
- If proposing: "Here's the audit plan we discussed"
- If scheduling: "I'd like to show you X in action - 30 min?"
- If closing: "Ready to move forward?"

Script:
---
Here's what I propose:
Phase 1: [What you'll do]
Timeline: [X weeks]
Investment: $X
Expected result: [their benefit]

Does this alignment work for you?
---

SECTION 4: Closing
- Make it easy to respond
- Provide multiple contact options
- Soft deadline (not pushy)

Script:
---
Reply to this email or [calendar link] to lock in a time.

Looking forward to helping you solve [their problem].

Best,
[Your name]
---

---

EMAIL VARIATIONS:

IF THEY WERE HOT (Very interested):
[More direct, shorter, faster CTA]

IF THEY WERE LUKEWARM (Maybe interested):
[More value-proof, longer, softer CTA]

IF THEY WERE COLD (Not interested yet):
[Educational, helpful, no hard CTA]

---

TIMING:
- Send within 24 hours of call (while fresh)
- Best day: Tuesday-Thursday
- Best time: 9-10am or 2-3pm their timezone
```

## PROMPT 7: Proposal Template

```
Title: Proposal Template Prompt
Description:
  Generate professional service proposal for client.
  Use this when: Client says "send me a proposal"
  How to use: Paste prompt + fill details + generate proposal
  Collection: Revenue-Prompts
Tags: #prompt #revenue #proposal #templates
```

**Prompt to paste:**
```
You are a proposal writer. Generate professional proposal.

CLIENT INFO:
- Company: [name]
- Contact: [name + title]
- Industry: [what they do]
- Challenge: [their specific problem]
- Budget: $X [if known]

SERVICE DETAILS:
- Service name: [your service]
- Problem it solves: [their specific pain]
- Your approach: [how you'll help]
- Deliverables: [what they get]
- Timeline: X weeks
- Investment: $X

TASK:
Generate proposal with 7 sections:

SECTION 1: Title Page
- Proposal title
- Client name
- Your company name
- Date
- Valid until: [date]

SECTION 2: Executive Summary (1 page)
- Situation/challenge (their pain)
- Proposed solution (your service)
- Expected outcome (their benefit)
- Investment required (price)
- ROI/payback period (if applicable)

SECTION 3: Current Situation
- What we learned in discovery call
- Their specific challenges
- Impact of not addressing it
- Current approaches (that aren't working)

SECTION 4: Proposed Solution
- Your approach (step-by-step)
- Why it works
- Why you're qualified
- How it solves their problem
- Expected outcomes

Format:
Phase 1: [What you'll do, timeline]
Phase 2: [What you'll do, timeline]
Phase 3: [What you'll do, timeline]

Deliverables:
- [What they receive]
- [What they receive]
- [What they receive]

SECTION 5: Investment
- Service fee: $X
- Optional add-ons: $Y
- Timeline for payment: [terms]
- Total investment: $Z

ROI Calculation (if applicable):
- Cost of problem (their annual loss): $X
- Your solution cost: $Y
- Payback period: X months
- Annual savings: $Z

SECTION 6: Next Steps
- Accept proposal: [process]
- Questions: [contact info]
- Timeline to start: [date]

SECTION 7: Terms & Conditions
- What's included
- What's not included
- Confidentiality
- Contract terms

---

TONE:
- Professional + warm
- Client-focused (use "you/your")
- Clear benefits, not features
- Confident but not arrogant
- Show expertise without being condescending

DESIGN:
- Include company logo
- Professional formatting
- Use colors/headers for readability
- Add testimonial/case study if you have one
```
