## 📝 Description détaillée

### Problème résolu
Les PME ont les mêmes vulnérabilités que les grandes entreprises mais **zéro budget pour un CISO** ou une équipe sécurité. Résultat: ransomware, fuites données, non-conformité coûtent en moyenne **$200,000+ par incident** pour une PME.

### Solution proposée — 3 tiers de service

#### 🥉 AUDIT DE BASE — $1,500
```
Durée       : 8h (2 jours)
Livrables   :
  ✅ Scan vulnérabilités réseau externe (Nmap + Nuclei)
  ✅ Audit politique mots de passe
  ✅ Revue accès utilisateurs + privilèges
  ✅ Rapport PDF : Top 10 risques + priorités
  ✅ Appel 30 min de présentation résultats
Format      : Rapport + appel vidéo
```

#### 🥈 AUDIT COMPLET — $3,000
```
Durée       : 16h (4 jours)
Livrables   :
  ✅ Tout l'audit de base +
  ✅ Pentest web (OWASP Top 10)
  ✅ Test phishing simulé (5 employés)
  ✅ Audit Microsoft 365 / Google Workspace
  ✅ Analyse backup & recovery
  ✅ Rapport détaillé + roadmap 90 jours
  ✅ Appel 60 min + présentation équipe
Format      : Rapport + slides + appel direction
```

#### 🥇 AUDIT + REMÉDIATION — $5,000
```
Durée       : 32h (1 semaine + suivi)
Livrables   :
  ✅ Tout l'audit complet +
  ✅ Implémentation 3 fixes critiques
  ✅ Formation équipe (2h cybersécurité basics)
  ✅ Policy sécurité rédigée (mot de passe, BYOD, remote)
  ✅ Suivi 30 jours post-audit
  ✅ Certificat de conformité (pour assureur/client)
Format      : Rapport + implémentation + formation + suivi
```

### Différenciation
- **Speed** : Rapport en 48-72h (vs. 2-4 semaines firmes traditionnelles)
- **Price** : 3-5x moins cher que grandes firmes ($15,000-50,000)
- **Language** : 100% francophone + culture PME québécoise
- **AI-powered** : Claude analyse + corrèle vulnérabilités → insights plus rapides
- **No jargon** : Rapport compréhensible pour non-techniciens (CEO/CFO)
