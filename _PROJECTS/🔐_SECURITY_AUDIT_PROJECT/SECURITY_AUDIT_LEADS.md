## 📧 OUTREACH STRATEGY

### LinkedIn approach

**Step 1: Connect first**
```
Message:
"Hi [Name], I've been following [company]'s growth.
Love what you're building in [industry].
Would be great to connect."

Goal: Get them to accept your connection
Timing: Wait 1 day
```

**Step 2: Value-add content**
```
After accepted, wait 3 days.
Share a relevant article about security/compliance
with personal note:

"Found this article on [PIPEDA/security/compliance].
Thought it might resonate given what you're doing at [company].
Cheers."

Goal: Build rapport, show you're interested
Timing: Wait 3-5 days
```

**Step 3: Soft pitch**
```
"Quick question: As a growing tech company,
have you had a professional security review?
Many CTOs find it super valuable before scaling.

Happy to chat if useful, no pressure."

Goal: Start conversation
Timing: Send if they've engaged (liked posts, etc.)
```

**Step 4: If interested - Direct message**
```
"Perfect! Sounds like it could be useful.
Can we grab 15 min call next week?
Just want to understand your setup + any concerns."

Goal: Book call
```

## 🎤 THE 15-MINUTE DISCOVERY CALL

**Goal:** Understand their situation + qualify them + propose audit

**Script:**

```
Opening (1 min):
"Thanks for jumping on a call. This should be quick.
I help tech companies identify security gaps before
they become problems. Sound useful?"

Discovery (8 min):
1. "What's your current tech setup look like?"
   (Listen for: cloud/on-prem, complexity)

2. "Any security concerns keeping you up at night?"
   (Listen for: real pain points)

3. "Have you had a security assessment before?"
   (Listen for: experience level)

4. "What does your security team look like?"
   (Listen for: resources, expertise)

5. "What would success look like?"
   (Listen for: compliance, peace of mind, audit requirements)

Pitch (5 min):
"Based on what you shared, here's what I'd recommend:

A comprehensive security audit covering:
- Infrastructure review
- App security
- Access control
- Compliance (PIPEDA)
- Incident response

It's $5,500, takes about 4 weeks, includes a full
report + 90-day support. Would that be useful?"

If yes:
"Great! I typically do 2/month to keep quality high.
Next slot is [DATE]. Want to lock that in?"

If objection:
"What would need to be different?"
(Listen, address, re-ask)

If no:
"No problem! Keep in touch, maybe in 6 months.
Happy to share some free resources in the meantime."

Close (1 min):
"Thanks again. Let me know if you have questions."
```

## 💬 OBJECTION HANDLING

**Common objections + responses:**

### Objection 1: "We don't have budget"

Response:
```
"I understand. Security audits often get deprioritized
until there's an incident. Two thoughts:

1. I work with companies to find budget. Many allocate
   this under 'IT operations' or 'risk management'.

2. Or, we could do a smaller scope first ($3.5K)
   and expand later?

Want to explore?"
```

### Objection 2: "We already have a security team"

Response:
```
"That's great! External audits are actually valuable
because we bring fresh perspective. Plus, it validates
your team's work.

Many companies with security teams still get external
audits annually. Might be worth a conversation?"
```

### Objection 3: "We're too small for a full audit"

Response:
```
"Actually, you're perfect size. Startups/SMBs often have
the most exposure because they're growing fast but security
hasn't caught up.

I have a Tier 1 audit ($3.5K, 25h) specifically for growing
companies like you. Want to chat?"
```

### Objection 4: "We'll think about it"

Response:
```
"Sure! A few things that help decision-making:

1. When would be realistic to revisit? (Get date)
2. Who else should I include in the conversation?
3. Any specific concerns I should address?

I'll send a one-pager on what's included."

[Send one-pager]
[Re-contact in 1 week]
```

### Objection 5: "Your price seems high"

Response:
```
"Happy to discuss! A few context:

Major audit firms charge $25K-50K for similar work.
I'm $5.5K because I focus specifically on SMBs.

What feels more reasonable to you? Or what would need
to be different?"

[If they push back further, offer Tier 1 at $3.5K]
```
