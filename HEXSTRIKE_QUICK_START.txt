❓ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

Issue: "Connection refused" error
→ Ensure Docker Desktop is running: docker ps

Issue: "Could not retrieve available tools"
→ Normal on first launch. Using fallback list with 150+ tools.
  Server initializing... Wait 30 seconds and refresh.

Issue: Port 8501 already in use
→ Close other Streamlit apps or restart system

Issue: Containers won't start
→ Check logs: docker-compose logs
→ Ensure Docker has enough resources

Issue: Very slow performance
→ Increase Docker memory allocation
→ Reduce number of running tools
