1. T-A-G (Task, Action, Goal)
    
    - Task : Définir la tâche ou l’activité
        
    - Action : Discuter l’objectif
        
    - Goal : Indiquer le résultat souhaité
        
2. B-A-B (Before, After, Bridge)
    
    - Before : Situation ou problème actuel
        
    - After : Résultat ou futur désiré
        
    - Bridge : Comment y parvenir
        
3. R-T-F (Role, Task, Format)
    
    - Role : Assigner un rôle ou une identité à l’IA
        
    - Task : Définir ce qui doit être accompli
        
    - Format : Structure de la réponse
        
4. C-A-R-E (Context, Action, Result, Example)
    
    - Context : Contexte ou historique
        
    - Action : Actions à réaliser
        
    - Result : Impact ou résultat attendu
        
5. R-I-S-E (Role, Input, Steps, Expectation)
    
    - Role : Identité ou expertise demandée
        
    - Input : Informations nécessaires
        
    - Steps : Étapes à suivre
        
    - Expectation : Ce à quoi s’attendre comme sortie
        
6. A-I-M (Action, Intent, Metric)
    
    - Action : Ce qui doit être fait
        
    - Intent : Intention ou but de la demande
        
    - Metric : Comment mesurer la réussite
        
7. G-R-O (Goal, Reason, Output)
    
    - Goal : Ce que vous voulez accomplir
        
    - Reason : Pourquoi c’est important
        
    - Output : Ce que l’IA doit produire
        
8. F-I-T (Format, Input, Task)
    
    - Format : Structure de la réponse désirée
        
    - Input : Informations à utiliser
        
    - Task : Tâche principale à effectuer
        
9. L-E-D (Level, Expectation, Direction)
    
    - Level : Définir le niveau de complexité
        
    - Expectation : Préciser ce que vous attendez
        
    - Direction : Style, ton ou format désiré
