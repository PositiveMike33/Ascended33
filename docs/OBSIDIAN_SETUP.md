## Prerequisites

### System Requirements

- **OS:** Windows 10+, macOS 10.15+, or Linux (Ubuntu 20.04+)
- **RAM:** Minimum 4GB (8GB recommended for large vaults)
- **Disk Space:** 10GB available (20GB+ for production use)
- **Network:** Internet connection for plugin downloads

### Required Software

- **Obsidian Desktop:** Version 1.4.0 or higher
- **Python:** Version 3.9 or higher
- **Git:** Version 2.30 or higher (for version control)
- **Node.js:** Version 16 or higher (for plugin development)

## Installation Steps

### Step 1: Download & Install Obsidian

1. Visit [https://obsidian.md](https://obsidian.md)
2. Download the installer for your operating system
3. Run the installer and follow on-screen instructions
4. Launch Obsidian after installation

### Step 2: Create Base Vault Directory

```bash
# Windows (PowerShell)
New-Item -ItemType Directory -Path "$env:USERPROFILE\Vaults\Ascended33" -Force
cd "$env:USERPROFILE\Vaults\Ascended33"
```

```bash
# macOS / Linux
mkdir -p ~/Vaults/Ascended33
cd ~/Vaults/Ascended33
```

### Step 3: Initialize Git Repository (Optional but Recommended)

```bash
git init
git config user.name "Your Name"
git config user.email "your.email@example.com"
echo "node_modules/" > .gitignore
echo ".obsidian/plugins/" >> .gitignore
echo ".obsidian/themes/" >> .gitignore
echo "__pycache__/" >> .gitignore
echo "*.pyc" >> .gitignore
```

### Step 4: Create Vault Structure in Obsidian

1. Open Obsidian
2. Click "Create new vault" (or "Open folder as vault")
3. Navigate to your Ascended33 directory
4. Name the vault: "Ascended33"
5. Click "Create"

Obsidian will automatically create the `.obsidian` configuration directory.

### Step 5: Configure Vault Settings

Once Obsidian opens with your vault:

1. **Open Settings** (gear icon or Ctrl+comma)
2. Navigate to **Files & Links**:
   - Enable: "Use [[Wikilinks]]"
   - Enable: "Automatically update internal links"
   - Disable: "Confirm file deletion"
3. Navigate to **Editor**:
   - Set "Tab indent size" to 2
   - Enable: "Fold heading"
   - Enable: "Fold indent"
4. Navigate to **Display**:
   - Choose your preferred theme (Dark recommended for investigation work)
   - Enable: "Show inline title"
5. Navigate to **Hotkeys**:
   - Search for "toggle preview mode" and set a shortcut (e.g., Ctrl+Shift+V)
6. **Exit Settings** and confirm the vault displays properly

### Step 2: Create Integration Script

Create `integrate_obsidian.py` in Ascended33 root:

```python
#!/usr/bin/env python3
"""
Ascended33 Obsidian Integration Script
Initializes bidirectional sync between Ascended33 and Obsidian vault
"""

import sys
import logging
from pathlib import Path
from ascended33_config import ASCENDED33_ROOT, VAULT_PATH

# Add core to path
sys.path.insert(0, str(ASCENDED33_ROOT / "core"))

from obsidian_sync_engine import ObsidianSyncEngine
from obsidian_ioc_linker import InvestigationGraphBuilder

logger = logging.getLogger(__name__)

def initialize_sync():
    """Initialize Obsidian sync engine"""
    logger.info("Initializing Obsidian Sync Engine...")
    
    try:
        # Initialize sync engine
        sync_engine = ObsidianSyncEngine(vault_path=str(VAULT_PATH))
        logger.info(f"✓ Sync engine initialized for vault: {VAULT_PATH}")
        
        # Initialize graph builder
        graph_builder = InvestigationGraphBuilder(vault_path=str(VAULT_PATH))
        logger.info("✓ Graph builder initialized")
        
        # Test vault connectivity
        vault_notes = sync_engine.vault.list_notes()
        logger.info(f"✓ Vault accessible. Found {len(vault_notes)} existing notes")
        
        print("\n✓ Obsidian integration successfully initialized!")
        print(f"  Vault location: {VAULT_PATH}")
        print(f"  Sync engine ready for bidirectional sync")
        print("\nNext steps:")
        print("  1. Run tests: python -m pytest tests/test_obsidian_sync.py -v")
        print("  2. Start sync watcher: python ascended33_watcher.py")
        print("  3. Begin investigation in Obsidian")
        
        return True
        
    except Exception as e:
        logger.error(f"✗ Integration failed: {str(e)}")
        return False

if __name__ == "__main__":
    success = initialize_sync()
    sys.exit(0 if success else 1)
```

Run the integration script:

```bash
python integrate_obsidian.py
```

### Step 3: Create Watcher Script

Create `ascended33_watcher.py`:

```python
#!/usr/bin/env python3
"""
Ascended33 Real-time Vault Watcher
Monitors Obsidian vault for changes and triggers sync
"""

import sys
import logging
from pathlib import Path
from ascended33_config import ASCENDED33_ROOT, VAULT_PATH

sys.path.insert(0, str(ASCENDED33_ROOT / "core"))

from obsidian_sync_engine import ObsidianSyncEngine

logger = logging.getLogger(__name__)

def start_watcher():
    """Start real-time vault watcher"""
    logger.info("Starting Obsidian Vault Watcher...")
    
    sync_engine = ObsidianSyncEngine(vault_path=str(VAULT_PATH))
    
    try:
        logger.info(f"✓ Watching vault: {VAULT_PATH}")
        logger.info("Press Ctrl+C to stop watching")
        sync_engine.start_watching()
    except KeyboardInterrupt:
        logger.info("✓ Watcher stopped")
    except Exception as e:
        logger.error(f"✗ Watcher error: {str(e)}")

if __name__ == "__main__":
    start_watcher()
```

## Backup & Recovery Strategy

### Automated Backup Configuration

#### Windows (Task Scheduler)

```batch
@echo off
REM Backup script for Ascended33 vault
set VAULT_PATH=%USERPROFILE%\Vaults\Ascended33
set BACKUP_PATH=%USERPROFILE%\Backups\Ascended33
set TIMESTAMP=%date:~-4,4%%date:~-10,2%%date:~-7,2%_%time:~0,2%%time:~3,2%

REM Create backup directory
if not exist "%BACKUP_PATH%" mkdir "%BACKUP_PATH%"

REM Copy vault (excluding .obsidian plugins cache)
xcopy "%VAULT_PATH%" "%BACKUP_PATH%\backup_%TIMESTAMP%" /E /I /EXCLUDE:C:\exclude.txt

echo Backup completed: %BACKUP_PATH%\backup_%TIMESTAMP%
```

Save as `backup_vault.bat` and schedule in Task Scheduler for daily runs.

#### macOS / Linux (Cron Job)

```bash
#!/bin/bash
VAULT_PATH="$HOME/Vaults/Ascended33"
BACKUP_PATH="$HOME/Backups/Ascended33"
TIMESTAMP=$(date +"%Y%m%d_%H%M%S")

mkdir -p "$BACKUP_PATH"

tar --exclude='.obsidian/plugins' \
    --exclude='node_modules' \
    --exclude='__pycache__' \
    -czf "$BACKUP_PATH/backup_$TIMESTAMP.tar.gz" \
    "$VAULT_PATH"

echo "Backup completed: $BACKUP_PATH/backup_$TIMESTAMP.tar.gz"
```

Schedule with cron:
```bash
0 2 * * * /path/to/backup_vault.sh  # Daily at 2 AM
```

```bash

# macOS / Linux
tar -xzf ~/Backups/Ascended33/backup_20250219_020000.tar.gz -C ~/
```

**Scenario 2: Revert from Git History**

```bash
# View recent commits
git log --oneline -10

# Revert to specific commit
git checkout <commit-hash>

# Or restore single file
git checkout <commit-hash> -- path/to/file.md
```

**Scenario 3: Recover Deleted Note**

```bash
# Find deleted file in git history
git log --diff-filter=D --summary | grep "delete mode"

# Restore deleted file
git checkout <commit-hash>^ -- path/to/deleted/file.md
```

## Troubleshooting Guide

### Obsidian Won't Start

**Problem:** Obsidian crashes on launch  
**Solution:**
```bash
# Clear cache and restart
# Windows: Delete C:\Users\YourUsername\AppData\Roaming\obsidian
# macOS: Delete ~/Library/Application\ Support/obsidian
# Linux: Delete ~/.config/obsidian

# Reinstall if issue persists
```

### Sync Engine Error: "ModuleNotFoundError: No module named 'watchdog'"

**Problem:** Missing Python dependency  
**Solution:**
```bash
# Activate virtual environment
source venv/bin/activate  # or .\venv\Scripts\Activate.ps1 on Windows

# Reinstall dependencies
pip install -r requirements.txt
```

### Wikilinks Not Working

**Problem:** `[[Note]]` syntax shows raw instead of links  
**Solution:**
1. Open Settings → Files & Links
2. Enable "Use [[Wikilinks]]"
3. Disable "New link format" (if it exists)
4. Restart Obsidian

### Dataview Queries Return Empty Results

**Problem:** `\`\`\`dataview` blocks show no results  
**Solution:**
1. Verify Dataview plugin is installed and enabled
2. Check folder paths match exactly (case-sensitive on Linux/macOS)
3. Verify note YAML frontmatter contains required fields
4. Open Dataview settings and enable "Show inline error"

### Graph Not Showing IOC Connections

**Problem:** IOCs don't appear as nodes in graph  
**Solution:**
```bash
# Rebuild graph index
python -c "from core.obsidian_ioc_linker import InvestigationGraphBuilder; \
    graph = InvestigationGraphBuilder('vault'); \
    graph.build_investigation_graph('Investigations/test')"
```

### Performance Issues / Slow Search

**Problem:** Obsidian becomes sluggish with large vault  
**Solution:**
```bash
# Optimize vault
1. Settings → Editor → Disable inline preview
2. Settings → Display → Reduce animation settings
3. Disable unused community plugins
4. Archive old investigations to Archive/ folder
5. Clear cache: Delete .obsidian/cache folder
```

### Encoding Issues with Special Characters

**Problem:** Special characters appear garbled in IOC notes  
**Solution:**
1. Ensure all files are UTF-8 encoded
2. Settings → Files & Links → Set encoding to UTF-8
3. Restart Obsidian

### Cannot Connect to Sync Engine

**Problem:** Obsidian notes not syncing to Python backend  
**Solution:**
```bash
# Check if sync engine is running
python ascended33_watcher.py

# Verify vault path in ascended33_config.py matches Obsidian location

# Check logs for errors
tail -f logs/ascended33.log

# Restart sync engine
pkill -f obsidian_sync_engine  # or use Task Manager
python ascended33_watcher.py
```

### IOC Linker Creating Duplicate Backlinks

**Problem:** Duplicate backlinks appearing in IOC notes  
**Solution:**
```python

for link in note_content.findall(r'\[\[([^\]]+)\]\]'):
    existing_links.add(link)

    if ref not in existing_links:
        # Create link
```

## Advanced Configuration

### Custom IOC Extractors

Create custom IOC extraction patterns in `core/custom_extractors.py`:

```python
import re
from typing import List, Tuple

class CustomIOCExtractor:
    """Custom patterns for specific IOC types"""
    
    @staticmethod
    def extract_cryptocoins(text: str) -> List[Tuple[str, str]]:
        """Extract cryptocurrency addresses"""
        patterns = {
            'btc': r'\b[13][a-km-zA-HJ-NP-Z1-9]{25,34}\b',
            'eth': r'\b0x[a-fA-F0-9]{40}\b',
            'xmr': r'\b4[0-9AB][1-9A-HJ-NP-Za-km-z]{93}\b'
        }
        
        results = []
        for coin_type, pattern in patterns.items():
            for match in re.finditer(pattern, text):
                results.append((coin_type, match.group()))
        return results
    
    @staticmethod
    def extract_phone_numbers(text: str) -> List[str]:
        """Extract international phone numbers"""
        pattern = r'(?:\+\d{1,3}[-.\s]?)?\(?\d{3}\)?[-.\s]?\d{3}[-.\s]?\d{4}'
        return re.findall(pattern, text)

    @staticmethod
    def extract_file_paths(text: str) -> List[str]:
        """Extract Windows and Unix file paths"""
        patterns = [
            r'[A-Z]:\\(?:[^\\/:*?"<>|\r\n]+\\)*[^\\/:*?"<>|\r\n]*',  # Windows
            r'(?:\/[a-zA-Z0-9_\-\.]+)*\/[a-zA-Z0-9_\-\.]*'  # Unix
        ]
        results = []
        for pattern in patterns:
            results.extend(re.findall(pattern, text))
        return results
```

For team investigations with audit trails:

```python
import json
from datetime import datetime
from pathlib import Path
from cryptography.fernet import Fernet

class MultiUserSync:
    """
    Multi-user sync with audit trail
    Each user change is cryptographically signed
    """
    
    def __init__(self, vault_path: str, user_id: str):
        self.vault_path = Path(vault_path)
        self.user_id = user_id
        self.audit_log = self.vault_path / ".audit" / "changes.log"
        self.audit_log.parent.mkdir(exist_ok=True)
    
    def sign_change(self, file_path: str, content: str, change_type: str) -> dict:
        """Create cryptographically signed change record"""
        
        content_hash = hashlib.sha256(content.encode()).hexdigest()
        timestamp = datetime.utcnow().isoformat()
        
        change_record = {
            "timestamp": timestamp,
            "user": self.user_id,
            "file": file_path,
            "change_type": change_type,
            "content_hash": content_hash,
            "signature": self._create_signature(content_hash)
        }
        
        # Append to audit log
        with open(self.audit_log, 'a') as f:
            f.write(json.dumps(change_record) + '\n')
        
        return change_record
```

1. **Check Logs:** Review `logs/ascended33.log` for error details
2. **Run Tests:** Execute `pytest tests/ -v` to diagnose issues
3. **Community Forum:** Post on Obsidian forum with `.obsidian/community-plugins.json` attached
4. **GitHub Issues:** Report bugs with reproduction steps
