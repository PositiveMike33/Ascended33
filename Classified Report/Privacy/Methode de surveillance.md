La vidéo de Jeff Hampton (Hampton Law) détaille les méthodes de surveillance policière moderne et propose des contre-mesures pratiques. Durée : 24 minutes, publiée le 8 février 2026. [youtube](https://www.youtube.com/watch?v=cgFPL-Mv47Q)

## Méthodes de surveillance
Les policiers collectent massivement des données : métadonnées téléphoniques, localisation via Stingray ou courtiers de données, mandats géofence, traces internet/cloud, réseaux sociaux, caméras avec reconnaissance faciale, lecteurs de plaques (ALPR), drones, ShotSpotter, IoT domestique, spyware, police prédictive et ADN généalogique. [youtube](https://www.youtube.com/watch?v=cgFPL-Mv47Q)

Ces outils forment un "stack" cumulatif pour profiler les individus sans surveillance ciblée initiale. [youtube](https://www.youtube.com/watch?v=cgFPL-Mv47Q)

## Mesures de protection
10 étapes clés : mot de passe fort + chiffrement téléphone ; désactiver localisation inutiles ; limiter traçage pubs ; chiffrement E2E (Signal) ; minimiser stockage cloud ; discipline réseaux sociaux ; muter IoT ; couvrir caméras ; prudence événements publics ; connaître droits (4e/5e amendements US).[1, {ts:1322}]
