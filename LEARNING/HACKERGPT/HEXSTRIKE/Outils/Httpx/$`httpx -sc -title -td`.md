# 🎓 Leçon : Maîtriser la Reconnaissance avec HTTPX  
  
La commande étudiée :  
`httpx -sc -title -td`  
  
**📝 Ce que fait cette commande  
Cette commande traite une liste de domaines ou d'adresses IP pour interroger leurs services web et extraire trois métadonnées critiques :  
  
* **`-sc` (Status Code) :** Affiche le code d'état HTTP (ex: 200 OK, 403 Forbidden, 404 Not Found). Cela permet de savoir si la page est accessible.  
* **`-title` (Page Title) :** Extrait le contenu de la balise HTML `**
