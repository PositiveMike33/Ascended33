## ⚠️ Important reminders

### Templates are your friends
- Never create note from scratch
- Use templates: `_TEMPLATES/` folder
- They guide structure + completeness

### Commands are triggers
- Just say the command naturally
- Claude recognizes pattern automatically
- No need to format perfectly

### Linking matters
- Link notes to related notes
- Link to templates used
- Create web of connections
- Makes vault searchable + useful

### Update regularly
- Add insights after learnings
- Update MEMORY.md monthly
- Review AUDIT.md quarterly
- Keep INDEX.md fresh
