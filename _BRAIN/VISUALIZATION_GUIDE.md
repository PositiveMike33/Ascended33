## 🎨 Visual Effects Explained

### Neuron Glow
- **Faint glow** = Baseline (ready but idle)
- **Bright glow** = Actively firing
- **Pulsing glow** = Processing signal
- **Fading glow** = Returning to idle

### Connection Lights
- **Dim line** = Potential path (connected but not active)
- **Bright line** = Active signal propagating
- **Animated line** = Real-time data flow
- **Faded line** = Recently used, cooling down

### Scene Rotation
- **Slow continuous rotation** = Visual feedback (brain is "thinking")
- **Faster rotation during activation** = Increased processing

## 🔧 Customizing the visualization

### Option 1: Change command mappings
Edit `BRAIN_VISUALIZATION.html`:

```javascript
const commandMap = {
    'idée revenu': [0, 1, 2, 3, 4],      // Your custom neurons
    'your-command': [0, 3, 5],           // Add new command
    // ...
};
```

### Option 2: Add more neurons
Edit the `neurons` array to add new neural nodes:

```javascript
{ name: 'YOUR_NEURON', pos: [x, y, z], color: 0xrrggbb, size: 5 }
```

### Option 3: Change colors
Modify the `color` values (RGB hex format):
- `0xffaa00` = Gold
- `0x00aaff` = Blue
- `0xff00ff` = Magenta
- `0x00ff88` = Green

### Option 4: Adjust rotation speed
Change these lines:
```javascript
scene.rotation.x += 0.0002;  // Slower X rotation
scene.rotation.y += 0.0005;  // Slower Y rotation
```

## 🌟 Advanced: Extending the visualization

### Option 1: Add real data from vault
Instead of simulated neurons, pull actual notes:

```javascript
// Pseudo-code:
fetch('api/vault/notes')
  .then(notes => {
    // Create neuron for each note
    notes.forEach(note => {
      createNeuron(note.name, note.connections);
    });
  });
```

### Option 2: Real-time sync
Show live updates as notes are created:

```javascript
// Listen for new notes
websocket.on('note-created', (note) => {
  activatedNeurons.add(getFullNeuronIndex());
  // Visual flash shows new note in network
});
```

### Option 3: Command history
Show recent commands and their activation patterns:

```javascript
// Timeline of commands
history.forEach((cmd, idx) => {
  addHistoryEntry(cmd, neuronActivation[idx]);
});
```
