# Learning Tracker Subagent

**Purpose:** Autonomous weekly progress tracking for cybersecurity learning across 4 phases (Beginner → OSCP)

**Schedule:** Every Tuesday at 19:00 EST | **Manual Trigger:** `/progress-check`

**Status:** ACTIVE ✅ | **Last updated:** 2026-02-20

---

## 🎯 Core Functionality

This subagent runs automatically once per week (or on manual trigger) to:

1. **Read learning data** from THIRTY3/daily/ directory (last 7 days)
2. **Parse daily notes** and extract metrics (time logged, challenges, concepts, blockers)
3. **Cross-reference phase definitions** from RESSOURCES_LEARNING.md
4. **Generate weekly report** with progress analysis and adaptive recommendations
5. **Update progress dashboard** (INDEX_DAILY.md and learning widget in _BRAIN/DASHBOARD.md)

---

## 📊 Data Sources

### Primary Input: THIRTY3/Daily/

**Location:** `THIRTY3/daily/2026/MM/YYYY-MM-DD_learning_progress.md`

**Read pattern:**
- All files from last 7 days
- Parse YAML frontmatter: date, type, phase, tags, status
- Extract content sections:
  - Today's activities (time spent, challenges completed)
  - Concepts mastered (learning achievements)
  - Blockers (obstacles encountered)
  - Progress tracking (phase %, milestones)

**Example reading:**
```markdown
---
date: 2026-02-20
type: learning-progress
phase: [2]
tags: [learning, phase-2, ctf, exploitation]
status: active
---

## 📚 Today's Activities
- Challenge: TryHackMe/OWASP Injection (45 min) — Solved
- Concept: SQL Injection exploitation (30 min) — Mastered
- OSINT: [[ENQUETES_OSINT/ACTIVES/Phishing_Campaign]] — 2 hours investigation

## ✅ Concepts Mastered Today
- SQL Injection: From understanding to exploitation
- Authentication bypass via injection
- Blind SQL Injection timing attacks
```

### Secondary Sources

1. **RESSOURCES_LEARNING.md** — Phase definitions, target hours, certification paths
2. **ENQUETES_OSINT/ACTIVES/** — Active investigation links from daily notes
3. **_BRAIN/DASHBOARD.md** — Current learning widget state
4. **HACKERGPT/RESSOURCES_LEARNING.md** — Reference learning resources

## 📋 Weekly Report Generation

### Input Processing

For each daily note in the 7-day window:

1. **Extract time logged:**
   - Sum all "Time: [X] min" entries across all activities
   - Cumulative time for current phase

2. **Track challenges:**
   - Platform (TryHackMe, HackTheBox, PortSwigger)
   - Challenge name and difficulty
   - Status (Solved, In Progress, Blocked)
   - Time spent

3. **Identify concepts:**
   - Extract from "Concepts Mastered" section
   - Build learning achievement list
   - Cross-reference with phase curriculum

4. **Assess blockers:**
   - Parse "Blockers" section
   - Track attempted solutions
   - Identify patterns (same blocker recurring?)

5. **Calculate phase progress:**
   - Current cumulative time / target hours for phase
   - Percentage complete
   - Estimated completion date (based on weekly velocity)

## 🤖 Execution Flow

### Automatic Trigger (Tuesday 19:00 EST)

1. **Initialize:**
   - Read `.claude/settings.json` for configuration
   - Determine date range (last 7 days)
   - Connect to data sources

2. **Data Collection:**
   - Query `THIRTY3/daily/2026/MM/` for files matching last 7 days
   - For each file:
     - Parse YAML frontmatter
     - Extract content sections
     - Calculate time, challenges, concepts
   - Aggregate metrics across all 7 days

3. **Analysis:**
   - Calculate total time logged (cumulative + weekly)
   - Track phase progress (% toward target hours)
   - Estimate completion date based on velocity
   - Identify blockers and patterns
   - Score learning progress (concepts/challenges per hour)

4. **Report Generation:**
   - Create comprehensive weekly report
   - Generate adaptive recommendations
   - Format for human readability
   - Output to `_BRAIN/WEEKLY_HACKING_PROGRESS.md`

5. **Dashboard Update:**
   - Update `THIRTY3/daily/INDEX_DAILY.md` with latest metrics
   - Calculate learning widget state
   - Update streak, velocity, OSCP countdown

### Manual Trigger (/progress-check)

Same execution flow as automatic, but user-initiated. Can be run anytime to generate instant progress report.

## 📈 Metrics Calculated

### Time Metrics
- **Daily:** Minutes logged per activity type (CTF, concept study, OSINT)
- **Weekly:** Total hours for the week
- **Cumulative:** Total hours toward current phase target
- **Velocity:** Average hours per week (helps estimate completion date)

### Achievement Metrics
- **Challenges:** Count by platform, difficulty level, status (solved/in-progress/blocked)
- **Concepts:** New concepts mastered this week (extracted from notes)
- **Blockers:** Count and resolution status

### Progress Metrics
- **Phase %:** Cumulative time / target hours (e.g., 35h / 80h = 43.75%)
- **Velocity:** Weekly hours (e.g., 8h/week → 10 weeks to complete)
- **Estimated completion:** Current date + (remaining hours / weekly velocity)
