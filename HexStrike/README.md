# HexStrike — Base Opérationnelle Cybersécurité

> *HexStrike opère dans la lumière — légalement, éthiquement, efficacement.*
> *Protéger ceux qui ne savent pas qu'ils sont vulnérables.*

---

## Mission

HexStrike est la branche cybersécurité de THIRTY3.
Outils open source. Méthodologie rigoureuse. Éthique absolue.

**Clients cibles :** Journalistes, enquêteurs, entreprises québécoises, multinationales
**Objectif :** Identifier les vulnérabilités avant les attaquants — et les corriger

---

## Structure

| Dossier | Contenu |
|---------|---------|
| `OSINT/` | Méthodologie et arsenal OSINT |
| `Pentest/` | Méthodologie pentest et outils |
| `Bug Bounty/` | Plateformes, méthodologie, rapports |
| `Reverse Engineering/` | Analyse d'attaques pour la défense |
| `Engagements/` | Dossiers actifs par client |
| `Vulnerabilites/` | Base de connaissances vulnérabilités |

---

## Avant Tout Engagement

**Lire [[Cadre Legal — Quebec Canada]] — Ce n'est pas optionnel.**

Checklist pré-engagement :
- [ ] Autorisation écrite signée par le propriétaire du système
- [ ] Scope clairement défini (IPs, domaines, applications inclus/exclus)
- [ ] Dates de l'engagement confirmées
- [ ] Contact d'urgence du client disponible
- [ ] Environnement de lab isolé préparé
- [ ] Note créée dans `Engagements/`

---

## Intégration avec Ascended33

Ascended33 est la plateforme qui automatise les rapports HexStrike.
Voir le repo GitHub pour les outils de génération de rapports.

---

## Red Lines HexStrike

1. Aucun accès sans autorisation écrite
2. Aucune action hors scope, même si la vulnérabilité est évidente
3. Aucune conservation de données personnelles hors durée d'engagement
4. Aucune divulgation publique sans divulgation responsable (90 jours)
5. Aucun travail pour acteurs aux intentions illégales ou non éthiques
